# Sécurité

> **S'adresse à :** utilisateurs et contributeurs du template public.
>
> **Rôle :** indiquer comment signaler un problème de sécurité concernant le template sans exposer publiquement de données privées.

## Ne pas publier dans une issue

- secret, token ou clé ;
- donnée personnelle ;
- adresse ou détail d'une infrastructure privée ;
- configuration complète d'une installation réelle ;
- vulnérabilité directement exploitable.

Utilisez le signalement privé de vulnérabilité GitHub lorsqu'il est activé. À défaut, contactez en privé un mainteneur indiqué dans `.github/MAINTAINERS.md` sans inclure le secret lui-même.

Un secret exposé doit être révoqué et remplacé. Supprimer le message ou réécrire l'historique ne suffit pas.
