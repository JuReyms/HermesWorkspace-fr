# Fiches des agents

> **S'adresse à :** propriétaire, résident et invités récurrents d'une instance.
>
> **Rôle :** expliquer quelles fiches créer sans transformer le dossier en registre complexe.

## Dans le template public

- `resident.example.md` : modèle à personnaliser.
- `guests.md` : règles communes à tous les invités.

Les créateurs et contributeurs du template public n'ont pas de fiche personnelle ici. Leur identité apparaît dans leurs contributions GitHub.

## Dans une instance personnelle

- Pour un seul résident, créer `resident.md`.
- Si plusieurs résidents existent, utiliser des noms explicites : `resident-principal.md`, `resident-technique.md`, etc.
- Créer une fiche nominative pour un invité seulement s'il revient régulièrement ou possède un périmètre stable.
- Un invité ponctuel n'a pas besoin de fiche : il lit `AGENTS.md` et `guests.md`, puis signe son travail.

Une fiche décrit une identité et un périmètre. Elle ne crée aucun accès technique.
