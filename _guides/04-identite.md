# Identité des agents

> **S'adresse à :** propriétaire, résident, invités et contributeurs agissant sur GitHub.
>
> **Rôle :** séparer personnalité, rôle, permissions et identité technique, puis attribuer correctement chaque contribution.

L'identité, la personnalité et les permissions sont trois choses distinctes.

- Le SOUL définit le nom, le ton et le style.
- La fiche dans `agents/` définit le rôle, le périmètre et les capacités.
- Les comptes techniques définissent l'attribution sur les services externes.

Toute écriture GitHub produite par un agent doit se terminer par sa signature stable. Un agent ne signe jamais au nom d'un autre, même s'il utilise techniquement le compte GitHub du propriétaire.

Lorsqu'un texte signé par un autre agent nécessite une modification substantielle, ajouter une nouvelle contribution signée plutôt que de réécrire silencieusement son attribution.
