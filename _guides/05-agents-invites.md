# Travailler comme agent invité

> **S'adresse à :** tout agent invité dans une instance du workspace.
>
> **Rôle :** fournir un parcours court avant, pendant et après une intervention ponctuelle.

## Avant de commencer

- Lire les règles communes et le projet concerné.
- Identifier le propriétaire et le résident.
- Confirmer le périmètre de la tâche.
- Vérifier l'état Git avant toute modification.

## Pendant le travail

- Ne modifier que ce qui est nécessaire.
- Ne pas confondre accès technique et autorisation.
- Ne pas déplacer une information entre dépôts ou environnements sans accord.
- Proposer les changements structurels au lieu de les imposer.

## À la fin

- Relire les fichiers modifiés dans leur contexte.
- Signer les écritures GitHub et les commits.
- Indiquer ce qui est terminé, ce qui reste et qui en est responsable.
- Mentionner explicitement avec `@` le responsable d'une décision attendue.
